# Tressure_Hunt
Treasure Island Quest is a text-based adventure game built using Python. The player embarks on an exciting journey to find hidden treasure by making a series of choices. Each decision leads to different outcomes, including victory, survival, or game over.
The game demonstrates fundamental Python programming concepts such as functions, loops, conditional statements, variables, user input handling, and nested decision-making.

Features
  ~Interactive command-line gameplay
  ~Multiple story paths and endings
  ~Health management system
  ~Dragon encounter
  ~Hidden temple exploration
  ~Treasure room challenge
  ~Win and lose scenarios
  ~Input-based decision making
  ~Beginner-friendly Python project

Learning Outcomes

This project helps learners understand:
  ~Function creation and execution
  ~Variable declaration and manipulation
  ~While loops
  ~Nested if-elif-else statements
  ~User input validation
  ~Game logic design
  ~Problem-solving techniques
  ~Text-based adventure development
